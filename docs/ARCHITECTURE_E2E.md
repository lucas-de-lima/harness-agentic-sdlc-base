# Architecture E2E

## Goal

Execute the first real architecture-deliberation workflow from a validated Project Profile to an ADR-ready decision.

## Flow

Discovery Complete -> Project Profile -> Architecture Agent -> Candidate comparison -> Simplest viable baseline -> Selected architecture -> Architecture Decision -> ADR -> Review

## Success

The decision is accepted only when the profile is validated, the simplest viable architecture is explicit, alternatives are compared, selected architecture is justified, rejected alternatives are recorded, consequences and evolution triggers are documented, and an ADR is produced.
