# Real Project Discovery

## Purpose

Run Discovery against one real legacy project without modifying production code.

## Inputs

- real project repository
- inherited project specification
- existing source/configuration/tests
- Base Harness discovery skill

## Outputs

- repository inventory
- specification selection
- Project Profile draft
- evidence index
- risks
- unresolved questions

## Safety

Discovery is read-only with respect to the product.

The only expected output files should be written to a dedicated discovery output directory outside the product repository, unless the user explicitly chooses an in-repository location.

## Naming

Historical names are treated as context only.

The new product name and repository name must be deliberated independently of former school branding.
