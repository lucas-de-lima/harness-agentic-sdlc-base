# Real Project Discovery Flow

```text
Real Project
   ↓
Repository Root
   ↓
Inventory
   ↓
Specification Detection
   ↓
Specification Selection
   ↓
Source/Config/Test Inspection
   ↓
Project Profile
   ↓
Evidence
   ↓
Human Review
   ↓
Architecture Deliberation
```

## Stop conditions

Discovery stops when:

- the project boundary is ambiguous;
- multiple specifications are equally plausible;
- required information is unavailable;
- a material conflict exists between specification, tests, and implementation.

The agent records the ambiguity instead of guessing.
