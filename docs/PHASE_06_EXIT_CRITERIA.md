# Phase 06 Exit Criteria

Phase 06 is complete when:

- [ ] Work item taxonomy is approved.
- [ ] Epic/Feature/User Story/Task hierarchy is approved.
- [ ] Bug/Spike/Architecture Decision usage is approved.
- [ ] GitHub Project is defined as the operational backlog.
- [ ] Recommended Project views are approved.
- [ ] Recommended Project fields are approved.
- [ ] Work item state machine is approved.
- [ ] Project lifecycle is approved.
- [ ] Orchestrator ↔ GitHub responsibilities are approved.
- [ ] Local documentation is explicitly limited to durable engineering knowledge.
- [ ] Future MCP capabilities are identified without implementing them yet.
