# GitHub Project Views

## View 1 — Board

Name:

`Execution`

Layout:

Board

Column field:

`Status`

Purpose:

Daily execution and bottleneck visibility.

GitHub supports Board layouts with configurable columns based on a single-select or iteration field. citeturn197859search2

## View 2 — Table

Name:

`Backlog`

Layout:

Table

Purpose:

Complete work inventory.

Suggested visible fields:

- Title
- Status
- Type
- Priority
- Phase
- Effort
- Risk
- Assignees
- Parent Issue
- Sub-issues Progress

The table view supports filtering, grouping, sorting, and showing/hiding fields. citeturn197859search2

## View 3 — Roadmap

Name:

`Roadmap`

Layout:

Roadmap

Purpose:

Macro planning.

Use date/iteration fields only when actual planning requires them. Roadmap uses configurable date/iteration fields to place work on a timeline. citeturn197859search3

## View philosophy

These are three views over the same work state.

They are not three independent plans.
