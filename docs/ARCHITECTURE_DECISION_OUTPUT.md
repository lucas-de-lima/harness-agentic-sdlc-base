# Architecture Decision Output

## Required sections

### Decision

- selected architecture
- architecture level
- confidence

### Context

- relevant domain characteristics
- relevant technical characteristics
- relevant constraints

### Candidates

For each candidate:

- fit
- strengths
- weaknesses
- complexity cost
- material risks

### Simplicity baseline

Explicitly describe the simplest viable architecture.

### Rationale

Explain what evidence makes the selected architecture preferable.

### Rejected alternatives

Record why materially plausible alternatives were rejected.

### Consequences

- positive
- negative
- operational
- testing
- maintenance

### Future pressure

State what future condition would justify moving to a more complex architecture.

### Unresolved questions

Only material questions that could change the decision.
