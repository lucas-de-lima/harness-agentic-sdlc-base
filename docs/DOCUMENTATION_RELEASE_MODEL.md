# Documentation Release Model

## Required

- README describes what the system does
- setup/run instructions work
- test instructions work
- configuration is documented
- architecture decision is linked or summarized
- meaningful limitations are stated

## Portfolio readiness

Before public release, confirm:

- repository name is appropriate
- legacy school branding is not unnecessarily retained
- screenshots/examples are accurate when present
- architecture section explains real trade-offs
- project status is honest
