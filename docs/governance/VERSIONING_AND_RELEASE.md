# Versioning and Release

## Base Harness

The Base Harness follows semantic versioning.

### Major

Incompatible contract change.

### Minor

Backward-compatible capability addition.

### Patch

Backward-compatible correction.

## Dedicated Harness

Each Dedicated Harness records:

- Base Harness version
- Dedicated Harness version

Generation is not synchronization.

## Release artifact

A Base Harness release should include:

- source
- deterministic validation
- version identifier
- release notes
- compatibility notes when needed
