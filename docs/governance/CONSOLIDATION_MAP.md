# Consolidation Map

The Base Harness was developed incrementally across approved phases. This document
maps those phase outputs into the canonical repository.

## Governance

- Constitution + taxonomy → `docs/HARNESS_BASE_CONSTITUTION.md`, `docs/HARNESS_TAXONOMY.md`
- Architecture → `docs/ARCHITECTURE_*`
- Patterns + Go → `docs/PATTERN_*`, `docs/GO_ENGINEERING_STANDARDS.md`, `docs/ENGINEERING_ANTI_PATTERNS.md`
- Skills → `skills/base/*`
- Agents → `docs/*AGENT*`, `docs/*SQUAD*`, `docs/*AUTHORITY*`
- GitHub → `docs/GITHUB_*`
- MCP → `docs/MCP_*`, `docs/*MCP*`
- Workflows → `workflows/*`, `docs/WORKFLOW_*`
- Harness Factory → `docs/HARNESS_FACTORY_*`, `docs/DEDICATED_HARNESS_*`, `docs/PROJECT_PROFILE_*`
- Release → `docs/SDLC_COMPLETION_MODEL.md`, `docs/RELEASE_*`

## Deliberate consolidation

Phase-by-phase ZIPs were development checkpoints, not the canonical repository.
This repository is the consolidated Base Harness.
