# Implementation E2E Validation

## Before

- [ ] GitHub Task is Ready.
- [ ] Acceptance criteria are concrete.
- [ ] Architecture is Approved.
- [ ] No conflicting implementation execution exists.
- [ ] Repository is clean or baseline diff is recorded.

## During

- [ ] Task is claimed.
- [ ] Agent inspects before editing.
- [ ] Only relevant files are modified.
- [ ] Tests are added/updated.
- [ ] Go formatting runs.
- [ ] Tests run.
- [ ] Vet runs.
- [ ] Diff is inspected.

## After

- [ ] Acceptance criteria pass.
- [ ] No architecture change occurred.
- [ ] Handoff exists.
- [ ] Exactly one bounded evidence comment is written.
- [ ] Task is In Review.
- [ ] No unrelated GitHub resource changed.
- [ ] No Task is marked Done.
