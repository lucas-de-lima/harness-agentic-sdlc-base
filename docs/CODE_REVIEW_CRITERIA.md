# Code Review Criteria

Review:

1. Scope
2. Acceptance criteria
3. Correctness
4. Idiomatic Go and maintainability
5. Tests
6. Architecture alignment
7. Obvious security concerns
8. Operational behavior where relevant

## Severity

- Blocking — must be fixed
- Major — significant correctness, architecture, security, or maintainability issue
- Minor — non-blocking improvement

A reviewer may approve with Minor findings when they do not materially affect correctness.
