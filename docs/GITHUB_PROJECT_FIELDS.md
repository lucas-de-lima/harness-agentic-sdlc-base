# GitHub Project Fields

## Required fields

Keep the Project intentionally small.

### Status

Values:

- Backlog
- Ready
- In Progress
- In Review
- Blocked
- Done

### Priority

Values:

- P0
- P1
- P2
- P3

### Phase

Values:

- Discovery
- Architecture
- Planning
- Implementation
- Verification
- Release

### Effort

Values:

- XS
- S
- M
- L
- XL

### Risk

Values:

- Low
- Medium
- High

## Optional later fields

Do not add them now unless a real workflow needs them:

- Target Date
- Iteration
- Agent
- Workstream
- Architecture Area

## Principle

A field must have an operational consumer.

If no workflow, filter, grouping, report, or decision uses a field, do not add it.
