# GitHub Project Bootstrap Runbook

## Objective

Create the first real GitHub Project for a product repository using the Agentic SDLC model.

## Recommended sequence

1. Create or choose the product repository.
2. Create one primary Project associated with the repository.
3. Configure the project description and README.
4. Configure the required custom fields.
5. Configure the three primary views.
6. Configure issue types and hierarchy conventions.
7. Create the first Discovery work item.
8. Add it to the Project.
9. Set its initial state to `Ready`.
10. Validate the Project through Codex/GitHub MCP.

GitHub Projects can be created as organization or user projects, can import items from a repository, and support Table, Roadmap, or Board as initial layouts. Existing Projects can also be copied as templates. citeturn197859search0

## Primary Project

Recommended name:

`<Product Name> — Engineering`

Avoid generic names such as `Project`, `Backlog`, or `Development`.

## Project description

The description should explain:

- what repository the Project controls
- what work it tracks
- that GitHub is the operational source of truth
- that the Agentic SDLC may manage workflow state

## Project README

Include:

- lifecycle
- work item hierarchy
- status definitions
- link to repository
- link to harness documentation
- short description of agent involvement
