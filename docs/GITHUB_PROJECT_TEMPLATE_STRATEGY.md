# GitHub Project Template Strategy

## Phase 16

Create the first Project manually.

Do not build a reusable Project template yet.

## Reason

The first Project is a calibration artifact.

We want to discover:

- which fields are actually useful
- whether Board/Table/Roadmap views are sufficient
- where GitHub native automation helps
- where the Orchestrator must own state
- which issue types are useful in practice

## Later

After the pilot stabilizes, create an organization Project template.

GitHub supports project templates that can preserve views, fields, workflows, and insights. citeturn197859search0

## Principle

Template after learning, not before.
