# Implementation Planning Gate

## Purpose

Define the exact condition under which architecture becomes ready for implementation planning.

## Required approvals

- Project Profile approved
- Architecture Decision produced
- ADR produced
- Architecture Review = Approved

## Prohibited shortcut

Architecture approval does not authorize an agent to start coding.

## Next workflow

```text
Architecture Approved
        ↓
Implementation Planning
        ↓
Epic / Feature / User Story / Task
        ↓
Implementation
```

## Rationale

Planning and implementation remain distinct to preserve scope control and make the first engineering tasks explicit.
