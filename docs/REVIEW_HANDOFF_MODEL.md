# Review Handoff Model

## Approved

The handoff must identify:

- reviewed artifact
- gates passed
- residual risks
- downstream action

## Changes Requested

The handoff must identify:

- exact findings
- severity
- affected requirement/decision
- recommended remediation
- whether a new architecture deliberation is required

## Blocked

The handoff must identify:

- blocking prerequisite
- why review cannot proceed
- required next action
