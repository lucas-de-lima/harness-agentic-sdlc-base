# Phase 15 Exit Criteria

- [ ] Global-vs-project MCP constraint is documented and accepted.
- [ ] Official GitHub MCP is configured in Codex.
- [ ] Docker execution works.
- [ ] OAuth or another approved authentication method works.
- [ ] Read-only mode is enabled.
- [ ] Toolsets are limited to context/issues/projects.
- [ ] `codex mcp list` and `codex mcp get github --json` work.
- [ ] A harmless read-only GitHub request succeeds in Codex.
- [ ] No mutation tool is exposed in the first integration.
- [ ] Dedicated Harness policy for GitHub capability is documented.
- [ ] No GitHub write is performed in this phase.
