# Code Review E2E Validation

## Before

- [ ] Task In Review
- [ ] Implementation Handoff exists
- [ ] Diff is available
- [ ] Architecture Approved
- [ ] Review skill loaded

## During

- [ ] Reviewer inspects actual diff
- [ ] Reviewer inspects production changes
- [ ] Reviewer inspects tests
- [ ] Reviewer evaluates acceptance criteria
- [ ] Reviewer does not modify implementation

## After

- [ ] Review Report exists
- [ ] Review Handoff exists
- [ ] Decision recorded
- [ ] If Approved, Task = Done
- [ ] If Changes Requested, Task = In Progress
- [ ] If Blocked, Task = Blocked
