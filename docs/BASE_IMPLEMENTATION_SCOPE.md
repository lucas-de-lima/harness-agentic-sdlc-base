# Base Implementation Scope

## Goal

Turn the approved Base Harness design into a small, testable repository.

## Phase 11 delivers

- executable `harnessctl`
- Base Harness validation
- Project Profile input
- deterministic Dedicated Harness generation
- Dedicated Harness validation
- repository templates
- Docker execution
- unit tests
- Base repository agent instructions

## Explicitly deferred

- autonomous Orchestrator runtime
- live GitHub mutations
- custom MCP servers
- LLM API integration
- automatic architecture decisions
- fully autonomous project discovery

## Principle

Implement deterministic infrastructure first. The agentic layer sits on top of reliable foundations.
