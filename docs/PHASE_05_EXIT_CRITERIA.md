# Phase 05 Exit Criteria

Phase 05 is complete when:

- [ ] Agent contract is approved.
- [ ] Core squad roles are approved.
- [ ] Authority and write permissions are defined.
- [ ] Handoff states and required handoff data are approved.
- [ ] Orchestration loop is approved.
- [ ] Failure and escalation paths are defined.
- [ ] Dedicated Harness specialization rules are compatible with the Base Constitution.
- [ ] No unresolved role overlaps materially affect implementation or review.

When all criteria are satisfied, Agent System design is frozen for the initial Harness Base v1 and implementation can proceed to the next phase.
