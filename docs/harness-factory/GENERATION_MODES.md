# Harness Generation Modes

## Inspect

Read-only. Produce a Project Profile proposal and detected repository characteristics.

## Plan

Read-only. Produce the proposed Dedicated Harness manifest and capability selection.

## Generate

Write `.harness/` files but do not commit.

## Validate

Check consistency between the Dedicated Harness and the selected Base capabilities.

## Commit

Not part of automatic generation.

The user or a separate Git workflow decides when to commit.
