# Architecture Review Criteria

A reviewer should be able to answer:

1. Does the selected architecture satisfy explicit requirements?
2. Is the complexity justified?
3. Was the simplest viable baseline considered?
4. Are alternatives and trade-offs visible?
5. Are assumptions separated from facts?
6. Could a simpler architecture be equally effective?
7. Is any technology choice premature?
8. Is there a concrete trigger for future architectural evolution?

A review should reject architecture when complexity is introduced without a concrete system benefit.
