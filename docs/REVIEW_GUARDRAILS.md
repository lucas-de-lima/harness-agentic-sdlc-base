# Review Guardrails

## Mandatory

- inspect evidence
- distinguish facts from preferences
- use governing criteria
- record findings
- preserve traceability
- make decision explicit

## Forbidden

- approval by default
- approval because tests pass alone
- rejection because reviewer prefers another style
- silent artifact modification
- expanding scope during review
- changing requirements to justify approval

## Escalation

Escalate when the reviewer discovers that the governing specification itself is contradictory or materially incomplete.
