# Release Report

## Required fields

- project
- release_identifier
- commit
- generated_at
- functional_gates
- build_gates
- quality_gates
- security_gates
- runtime_gates
- documentation_gates
- ci_gates
- waivers
- final_decision
- residual_risks
- next_action

## Final decisions

- `Release Ready`
- `Release Blocked`

## Evidence

Every failed or waived gate must contain evidence.
