# Go Engineer E2E

## Goal

Execute the first real implementation task through the Agentic SDLC.

## Flow

```text
GitHub Task: Ready
        ↓
Go Engineer
        ↓
Claim → In Progress
        ↓
Inspect
        ↓
Implement
        ↓
Validate
        ↓
Self-check
        ↓
Handoff
        ↓
In Review
```

## Scope

Use one small implementation Task from the pilot project.

The Task should have:

- narrow scope
- clear acceptance criteria
- resolved dependencies
- no expected architecture change
- low external dependency risk

## Success

The implementation is successful when:

- only task-related files change
- acceptance criteria pass
- required tests pass
- Go quality checks pass
- architecture remains unchanged
- implementation handoff is complete
- Task reaches `In Review`
