# Phase 07 Exit Criteria

Phase 07 is complete when:

- [ ] Native capability vs CLI/script vs MCP vs external integration boundary is approved.
- [ ] MCP adoption policy is approved.
- [ ] GitHub MCP is approved as an existing capability.
- [ ] Initial GitHub MCP toolsets are approved.
- [ ] Docker and Go tooling are explicitly CLI-first.
- [ ] MCP permission tiers are approved.
- [ ] Agent/tool authority matrix is approved.
- [ ] Custom MCP admission criteria are approved.
- [ ] MCP versioning policy is approved.
- [ ] No unnecessary custom MCP has been accepted into the Base Harness.
