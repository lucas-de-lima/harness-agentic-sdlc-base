# Project Profile Specification

## Purpose

Define the canonical intermediate representation produced during project discovery.

The Project Profile is the bridge between an ambiguous legacy project and deterministic harness generation.

## Required sections

### Identity

- proposed product name
- proposed repository name
- short description
- problem statement
- legacy naming references to ignore

### Domain

- actors
- core concepts
- entities
- business rules
- primary workflows

### Technical

- application type
- interfaces
- persistence
- external dependencies
- concurrency characteristics
- operational requirements

### Constraints

- explicit requirements
- inferred requirements
- known limitations
- non-goals

### Risks

- ambiguity
- legacy behavior uncertainty
- integration uncertainty
- architecture uncertainty

### Open questions

Only unresolved information that could materially change implementation.

## Status

A Project Profile is not a final specification. It is an evidence-backed model used for architectural deliberation and planning.
